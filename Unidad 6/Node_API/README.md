# ✅ **1. Using Express Generator (simple REST API template)**

**Express** is the most popular framework for simple REST APIs.

### **Install the generator globally:**

```bash
npm install -g express-generator
```

### **Generate a project:**

```bash
express my-api
```

### **Install dependencies:**

```bash
cd my-api
npm install
```

### **Run it:**

```bash
npm start
```

This gives you a basic Express project with a folder structure like:

```
my-api/
 ├─ app.js
 ├─ routes/
 ├─ public/
 └─ bin/www
```

You can then create routes in `/routes`.
